# Prodigy A Level Sociology

AQA Sociology 7192: 72 concise revision lessons across education, methods, theory, crime and all eight Paper 2 options. Each has explained concepts, critical discussion, a fictional worked application, two checks and a written task. Named ideas supplement selected topics. These are revision summaries, not a substitute for a taught course or a complete research bibliography.

Students explicitly choose one topic from each of the two option groups. No school combination is preset. Paper 2 is assembled from those choices and retains separate saved answers for all 16 combinations. Papers 1 and 3 are compulsory. Each original, unofficial paper is 80 marks in 120 minutes, with timers, printable questions and indicative mark schemes. Extended answers use holistic guidance rather than keyword ticks. No official grade boundaries are claimed.

The Research Lab uses fictional data to explore sampling bias, percentage-point differences and relative change, and the trade-offs of methods in educational contexts. It does not invite collection of sensitive personal data. An essay planner saves separate plans per topic. Topic search, resume, optional accounts, classes, assignments and server-side optional AI marking use the shared Prodigy platform.

Edit course.json, paper-bank.json and site-meta.json; run node scripts/build.cjs, then node --test. Sources and provenance are recorded in provenance.json and the course footer. The Supabase backend must permit alevel-sociology and the shared assignment service must contain the new course catalogue. API secrets stay on the server. Teachers use their existing Prodigy account; student access is through a class.
